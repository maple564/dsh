# 真实运行展示：录制清单

目标：录一段真实 DSH 操作，让新用户看到“追问后能回来”。目前仓库首页是示意图，尚无当前版实机录像。

## 需要交回的素材

一段 MP4 原始录屏（可以 1–3 分钟，模型等待保留即可），或下列三个状态的 PNG。建议 1280×720 以上，仅录 DSH 内容区；使用新建示例会话，收起私人侧栏，不显示账号和设置。无需剪辑，无需重新跑完整验收。

1. 主线回答中选中“幂等键”，下方可见追问输入框。
2. 支线出现真实回答，树中可见当前分支；最好同时有“游标分页”平行支线。
3. 填写一句结论后返回原文，展开结论卡片，结构树同时可见。

## 可直接使用的演示内容

主线问题：请用一段纯文本，简要介绍订单 API 中的幂等键和游标分页，不使用 Markdown 格式。

选中“幂等键”后追问：同一次下单重试，怎样避免重复创建订单？请简短回答。

回填结论：同一次业务操作复用同一幂等键，服务端保存处理结果并在重试时返回。

平行支线问题：游标分页为什么比页码分页更适合持续变化的数据？

## 发布处理

素材确认不含私人内容后，剪成约 20–30 秒 GIF 或短视频，标出“选中 → 追问 → 返回 → 切换”。如跳过模型等待，必须注明“等待过程已剪辑”。不能用 HTML 模拟预览冒充真实运行。

录制时附 DSH 版本、插件 client.js SHA256 和日期；记录失败并保留真实情况。这里只要求展示素材，不代表完整验收。
