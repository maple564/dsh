# Changelog

## 0.1.0-preview.1

First public preview candidate.

- Anchored follow-ups from supported selections into DSH child Sessions.
- Parallel/nested branches, foldable cards, pause/resume, manual return conclusions.
- Source message reading-position restoration when available.
- New topic branches without a selected-text anchor.
- IME-aware Enter submission.
- Current-path flow lines, direction arrows, location badge and reduced-motion support.
- Read-only import of optional Skill state outlines.
- Local state/visual demos and Desktop installation helper.

Known limits and validation boundaries are listed in docs/STATUS.md. Publication of this candidate does not mean the latest additions have passed full DSH GUI acceptance.
